# riscv-core-pipelined

A 5-stage pipelined RV32I RISC-V CPU core written in SystemVerilog.

## Project Structure

```
riscv-core-pipelined/
├── Makefile              # Regression harness: make test / waves / clean
├── rtl/                  # SystemVerilog hardware source files
│   ├── riscv_pkg.sv      # Shared types and constants (compiled first)
│   ├── core/             # CPU core modules (ALU, RegFile, Control, Hazard unit)
│   ├── lib/              # Generic primitives (mux2, mux3, adder)
│   ├── mem/              # Instruction and data memories
│   └── top/              # Top-level integration
├── tb/
│   └── system/           # Self-checking universal testbench
├── sw/
│   └── asm/              # Test programs (.hex) and expected results (.expected)
├── tools/                # Python generator for the test programs
└── build/                # Generated by make (compiled sim, logs, waveforms); not in git
```

## Prerequisites & Local Setup

This CPU is written in SystemVerilog and simulated using **Icarus Verilog**.

### 1. Install the Simulation Toolchain (macOS)

You will need Homebrew to install the simulation engine and waveform viewer. Open your terminal and run:

```bash
# Install Icarus Verilog (The Compiler/Simulator)
brew install icarus-verilog

# Install Surfer (The Waveform Viewer; native on Apple Silicon)
brew install surfer
```

### 2. Build & Run

```bash
# Compile and run every test in sw/asm/, print a PASS/FAIL summary.
# Exits non-zero if any test fails.
make test

# Run a single test (log in build/test_basic.log)
make build/test_basic.pass

# Record and open the waveform for one test
make waves T=test_alu
make waves T=test_alu WAVE_VIEWER=gtkwave   # use a different viewer

# Delete all build output
make clean
```

Adding a test needs no Makefile change: put `test_foo.hex` and
`test_foo.expected` in `sw/asm/` and it is picked up automatically.
